## 4. Scenario, profession and world options programmatically

- Scenario is **game state, not avatar state**: `const scenario *scen = nullptr` ([game.h:1139](../references/Cataclysm-DDA/src/game.h#L1139)); free accessors `get_scenario`/`set_scenario` ([game.cpp:14503-14510](../references/Cataclysm-DDA/src/game.cpp#L14503), declared [scenario.h:179-180](../references/Cataclysm-DDA/src/scenario.h#L179)).
- `avatar::create` **forcibly resets** both: `prof = profession::generic(); set_scenario( scenario::generic() );` ([newcharacter.cpp:749-750](../references/Cataclysm-DDA/src/newcharacter.cpp#L749)). So a fixed scenario cannot be installed *before* `create()` — it is overwritten.
- `create(NOW)` → `randomize(false, true)` ([newcharacter.cpp:795-797](../references/Cataclysm-DDA/src/newcharacter.cpp#L795)) which keeps `get_scenario()` ([newcharacter.cpp:462](../references/Cataclysm-DDA/src/newcharacter.cpp#L462), i.e. generic) and picks `scenario_from->weighted_random_profession()` ([:463](../references/Cataclysm-DDA/src/newcharacter.cpp#L463)).
- `Character::prof` is public ([character.h:584](../references/Cataclysm-DDA/src/character.h#L584)), as are `random_start_location` ([:595](../references/Cataclysm-DDA/src/character.h#L595)) and `start_location` ([:596](../references/Cataclysm-DDA/src/character.h#L596)). So `set_scenario(&scen)`, `get_avatar().prof = &prof`, `random_start_location = false`, `start_location = start_location_id(...)` are all writable after `create()` and before `start_game()`.
- Ordering consequence `[R]`: `add_profession_items()` runs inside `start_game()` ([game.cpp:922](../references/Cataclysm-DDA/src/game.cpp#L922), impl [newcharacter.cpp:620](../references/Cataclysm-DDA/src/newcharacter.cpp#L620)), so an overridden `prof` *does* yield that profession's items. `add_traits()` reads `prof->get_locked_traits()` and `get_scenario()->get_locked_traits()` ([newcharacter.cpp:4937-4952](../references/Cataclysm-DDA/src/newcharacter.cpp#L4937)) so it can be re-run; but `add_default_background()` already ran against `scenario::generic()` ([newcharacter.cpp:807-810](../references/Cataclysm-DDA/src/newcharacter.cpp#L807)) and hobbies were drawn from the old scenario ([newcharacter.cpp:478](../references/Cataclysm-DDA/src/newcharacter.cpp#L478)).
- World options are `WORLD::WORLD_OPTIONS`, pushed into the live options manager by `set_active_world` ([worldfactory.cpp:314](../references/Cataclysm-DDA/src/worldfactory.cpp#L314)); individual values can be written before or after. Global options: `get_options().get_option(x).setValue(y)`, precedent [test_main.cpp:120-127](../references/Cataclysm-DDA/tests/test_main.cpp#L120). Existing CLI hooks only cover two options ([main.cpp:810-818](../references/Cataclysm-DDA/src/main.cpp#L810)).

## 5. Obstacles

1. **`game_ui::init_ui()` blocks without a ≥80×24 terminal.** It reads `getmaxy(stdscr)`/`getmaxx(stdscr)` ([game.cpp:663-664](../references/Cataclysm-DDA/src/game.cpp#L663)) — null-safe, returning 0 ([ncurses_def.cpp:100-114](../references/Cataclysm-DDA/src/ncurses_def.cpp#L100)) — then `ensure_term_size()` loops `while( TERMY < 24 || TERMX < 80 )` calling `refresh(); getch();` ([ncurses_def.cpp:563-594](../references/Cataclysm-DDA/src/ncurses_def.cpp#L563)). `getch()` at [:593](../references/Cataclysm-DDA/src/ncurses_def.cpp#L593) blocks on the keyboard forever. No `test_mode` escape exists in that loop.
2. **`check_encoding()` blocks if the locale is not UTF-8**, inside the same `init_ui()` ([game.cpp:630](../references/Cataclysm-DDA/src/game.cpp#L630) → [ncurses_def.cpp:607-619](../references/Cataclysm-DDA/src/ncurses_def.cpp#L607), `getch()` at [:617](../references/Cataclysm-DDA/src/ncurses_def.cpp#L617)).
3. **`test_mode` and turn-driving are mutually exclusive.** `input_manager::get_input_event` throws in `test_mode` ([ncurses_def.cpp:410-415](../references/Cataclysm-DDA/src/ncurses_def.cpp#L410)); `pump_events` no-ops ([:383-387](../references/Cataclysm-DDA/src/ncurses_def.cpp#L383)).
4. **`do_turn()` blocks on input on the very first turn.** `start_game()` ends with `u.set_moves(0); u.process_turn()` ([game.cpp:995-996](../references/Cataclysm-DDA/src/game.cpp#L995)) and `process_turn` does `moves += get_speed()` ([character.cpp:2477](../references/Cataclysm-DDA/src/character.cpp#L2477)), so `u.get_moves() > 0` is true ([do_turn.cpp:564-565](../references/Cataclysm-DDA/src/do_turn.cpp#L564)) and `g->handle_action()` runs ([:588](../references/Cataclysm-DDA/src/do_turn.cpp#L588)) → `get_player_input` ([handle_action.cpp:244](../references/Cataclysm-DDA/src/handle_action.cpp#L244)) → `ctxt.handle_input()` ([:438](../references/Cataclysm-DDA/src/handle_action.cpp#L438)) → `inp_mngr.get_input_event()` ([input_context.cpp:444](../references/Cataclysm-DDA/src/input_context.cpp#L444)) → `getch()`. **Stopping after `start_game()` returns is the last input-free point.**
5. **World name is a hidden RNG consumer / debug trigger.** `WORLD::WORLD()` auto-names via snippet expansion ([worldfactory.cpp:73-76,78-85](../references/Cataclysm-DDA/src/worldfactory.cpp#L73)) and snippet expansion picks a random replacement ([text_snippets.cpp:250](../references/Cataclysm-DDA/src/text_snippets.cpp#L250)). Separately, `debug_menu::is_debug_character()` dereferences `active_world` ([debug_menu.cpp:542-549](../references/Cataclysm-DDA/src/debug_menu.cpp#L542)) and, if the world *or* character name starts with `Debug|Test|Sandbox|Staging|QA|UAT`, `start_game()` runs `debug_menu::do_debug_quick_setup()` ([game.cpp:1176-1179](../references/Cataclysm-DDA/src/game.cpp#L1176)). Use an explicit, non-debug world name.
6. **`--seed` is applied exactly once**, at [main.cpp:779](../references/Cataclysm-DDA/src/main.cpp#L779) via `rng_set_engine_seed` ([rng.cpp:208-213](../references/Cataclysm-DDA/src/rng.cpp#L208), which ignores `0`); default is `time(nullptr)` ([main.cpp:273](../references/Cataclysm-DDA/src/main.cpp#L273)). `start_game()` burns one draw on `seed = rng_bits()` ([game.cpp:902](../references/Cataclysm-DDA/src/game.cpp#L902)).
7. **`g->scen` is null until `avatar::create()`** ([game.h:1139](../references/Cataclysm-DDA/src/game.h#L1139)) and `start_calendar()` dereferences it unconditionally ([game.cpp:13537-13543](../references/Cataclysm-DDA/src/game.cpp#L13537)). `create()` must precede `start_game()`.
8. **Terminal size leaks into state.** `TERMX/TERMY` → `TERRAIN_WINDOW_*` ([game.cpp:3942-3945](../references/Cataclysm-DDA/src/game.cpp#L3942)), consumed by `mon_info_update` ([game.cpp:4652](../references/Cataclysm-DDA/src/game.cpp#L4652), read at [:4695](../references/Cataclysm-DDA/src/game.cpp#L4695)) which `do_turn` calls ([do_turn.cpp:568](../references/Cataclysm-DDA/src/do_turn.cpp#L568)) and by view-offset clamping ([game.cpp:8415-8428](../references/Cataclysm-DDA/src/game.cpp#L8415)). Pin the terminal size.
9. **Threads:** none in the start path `[R]` — the only `std::thread` in `src/` is a sound-effect thread ([sounds.cpp:1400](../references/Cataclysm-DDA/src/sounds.cpp#L1400)). **Wall clock:** `init_autosave()` stores `std::time(nullptr)` ([game.cpp:13473-13477](../references/Cataclysm-DDA/src/game.cpp#L13473)) and `time_of_last_load`/`playtime` are steady-clock ([game.cpp:1170](../references/Cataclysm-DDA/src/game.cpp#L1170), [:3657](../references/Cataclysm-DDA/src/game.cpp#L3657)). Excluding these from a state dump is `[I]`, not verified.

## 6. Recommended minimal sequence for the harness

Preconditions already met by the existing `--dump-env` path: `get_options().init()/load()` ([main.cpp:755-756](../references/Cataclysm-DDA/src/main.cpp#L755)), `init_colors()`, `catacurses::init_interface()` ([:765](../references/Cataclysm-DDA/src/main.cpp#L765)), `rng_set_engine_seed(cli.seed)` ([:779](../references/Cataclysm-DDA/src/main.cpp#L779)), `game_ui::init_ui()` ([:781](../references/Cataclysm-DDA/src/main.cpp#L781)), `g = make_unique<game>()` ([:783](../references/Cataclysm-DDA/src/main.cpp#L783)), `g->load_static_data()` ([:788](../references/Cataclysm-DDA/src/main.cpp#L788)).

1. `get_options().get_option( X ).setValue( Y )` for every pinned option (pattern: [test_main.cpp:120-127](../references/Cataclysm-DDA/tests/test_main.cpp#L120)); do it before `setup()` so world/mod code sees it.

## 7. What the recommended sequence does *not* do that the UI path does

- Never runs `worldfactory::show_worldgen_*`, so **no mod-compatibility check** ([worldfactory.cpp:195-200](../references/Cataclysm-DDA/src/worldfactory.cpp#L195)) and no `show_prompt`-driven world/options editing.
- Never runs `pick_world` ([worldfactory.cpp:454](../references/Cataclysm-DDA/src/worldfactory.cpp#L454)), so the "first save-less world" heuristic and the `TUTORIAL`/`DEFENSE` filtering are bypassed.
- Never runs `main_menu::opening_screen()`'s prologue: holiday detection, music, `init_strings()`, `load_char_templates()`, menu input contexts ([main_menu.cpp:579-612](../references/Cataclysm-DDA/src/main_menu.cpp#L579)).
- Never runs the scenario-description message and eternal-weather announcement ([main_menu.cpp:902-911](../references/Cataclysm-DDA/src/main_menu.cpp#L902)).
- Never runs interactive chargen: no point-pool/scenario/profession/background/stats/traits/skills/description tabs ([newcharacter.cpp:806-846](../references/Cataclysm-DDA/src/newcharacter.cpp#L806)), and therefore no `save_template( "Last Character" )` ([newcharacter.cpp:870](../references/Cataclysm-DDA/src/newcharacter.cpp#L870)).
- Does **not** reproduce a *matching* background/hobbies for an overridden profession: `add_default_background()` and `randomize_hobbies()` already ran against `scenario::generic()` ([newcharacter.cpp:807-810](../references/Cataclysm-DDA/src/newcharacter.cpp#L807), [:478](../references/Cataclysm-DDA/src/newcharacter.cpp#L478)). Old profession locked traits are also not removed by a later `add_traits()`.
- Never runs `game::load( save_t )` ([game.cpp:3228](../references/Cataclysm-DDA/src/game.cpp#L3228)): no `unserialize_master`, no `sees`/`player_filename` restore.
- Never runs `main_menu::load_game`'s bookkeeping: `last_world_name`/`last_character_name`/`save_last_world_info` ([main_menu.cpp:1060-1064](../references/Cataclysm-DDA/src/main_menu.cpp#L1060)).
- Never runs `game::gamemode` setup (`get_special_game`, `gamemode->init()`, [`main_menu.cpp:829-847`](../references/Cataclysm-DDA/src/main_menu.cpp#L829)); `start_game` substitutes a plain `special_game` ([game.cpp:898-900](../references/Cataclysm-DDA/src/game.cpp#L898)), so `gamemode->per_turn()` from turn 2 on is the no-op base.
- Never runs the post-quit `cleanup_at_end()` / `exit_handler` path ([do_turn.cpp:457-458](../references/Cataclysm-DDA/src/do_turn.cpp#L457), [main.cpp:867](../references/Cataclysm-DDA/src/main.cpp#L867)).
